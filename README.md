# Create: Random 'BulkSheet'

_"BulkSheet" has nothing to do with bulk processing or sheet metal. -holy censorship!_

Addon for [Create](https://www.curseforge.com/minecraft/mc-mods/create). There is no
grand vision here. There is no theme, no concept, no balance, no friends, no purpose in life, no "bulk sheets".

If you came looking for a coherent expansion pack with a design pillar and a roadmap: this isn't it.
This "fluffy" _(holy censorship! x2)_ mod is just my random fantasies I wanted to add. That's all.

## What's in the box for now?

- **Delayed Transporter** — moves items like a chute, except it holds onto them for a configurable
  amount of time first.


- **Fan Result Transporter** — grabs the result of a Create fan processing recipe and yeets it in a storage block


- **Abyssal Fluid Extractor** — a kinetic block that **extract** (duplicate, duh) fluid on top of it over time at a rate driven by RPM. (Supports [Recipe](Fluid%20extracting%20recipe%20reference.md))


- **Abyssal Fluid Tank** — a fluid tank whose capacity scales up the more **Nether Stars**, **Netherite Ingots** and **Diamonds** you feed it. Also supports Bottomless Supply, So you can make one block infinite fluids.


- **Abyssal Energy Tank** — same deal as the fluid tank, but for FE. Feed it rare materials, get more
  storage.
  

- **Reverse Redstone Link** — a Create Redstone Link that inverts the signal it receives. 15 in, 0 out. 13 in, 2 out. etc etc.
  Useful for the three people who needed this and didn't want to deal with redstone torch.
  

- **Void Star** — a crafting component that gates some of the above blocks behind an actual cost, so I can hear cute words about my family and living location ^^


- **Redstone Weight** *(requires [Sable](https://www.curseforge.com/minecraft/mc-mods/sable))* — a physics-enabled block
  that changes it weight with redstone signal (also multipler can be change up to 5 with wrench)



## Requirements

- Minecraft 1.21.1, NeoForge
- [Create](https://www.curseforge.com/minecraft/mc-mods/create) 6.0.7+
- [Sable](https://www.curseforge.com/minecraft/mc-mods/sable) — optional, only needed for the Redstone Weight block

## Configuration

Most of the "scales with rare materials" behavior (tank capacities, extraction rates, stress impact,
whether the Void Star requirement is even enforced) is configurable through the standard NeoForge
config screen/file. If a number feels off for your pack, go change it.
